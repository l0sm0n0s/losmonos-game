# Tipografías de Los Monos Game

## Pirata One — títulos

- Autores: Rodrigo Fuenzalida y Nicolas Massi.
- Archivo: `pirata-one/PirataOne-Regular.ttf`.
- Fuente: https://github.com/google/fonts/tree/main/ofl/pirataone
- Licencia: SIL Open Font License 1.1. El texto original se conserva en [pirata-one/OFL.txt](pirata-one/OFL.txt).
- Tipografía gótica para el título del menú, el letrero de la empresa y el título de victoria.

Se utiliza la fuente original, sin modificar.

## Poppins — botones, instrucciones y demás textos

- Autor: The Poppins Project Authors.
- Archivos: `poppins/Poppins-Regular.ttf` y `poppins/Poppins-SemiBold.ttf`.
- Fuente: https://github.com/google/fonts/tree/main/ofl/poppins
- Licencia: SIL Open Font License 1.1. El texto original se conserva en [poppins/OFL.txt](poppins/OFL.txt).
- Poppins Regular se aplica como fuente global; los botones usan Poppins SemiBold.

## Uso y distribución

Ambas familias permiten uso personal y comercial, así como su inclusión en el juego bajo la SIL Open Font License 1.1. Conservar los avisos de copyright y los archivos `OFL.txt` de ambas familias al distribuirlas. No vender los archivos tipográficos por separado. Las condiciones completas están en las licencias enlazadas.

La fuente de uso personal utilizada durante la prueba inicial fue retirada del proyecto. Solo se incluyen Pirata One y Poppins.

Fuentes consultadas y archivos descargados el 18 de septiembre de 2026.
