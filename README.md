# Los Monos Game

Colección de minijuegos sobre las distintas actividades de un turno de trabajo en la empresa **LosMonos**, creada con Godot 4.

## Cómo jugar

- Muévete con las flechas del teclado.
- Usa `Espacio` para recoger y soltar objetos.
- Usa `Esc` para volver al menú.

## Actividad 01: clasificación de paquetes

La máquina de la bodega produce un lote de cinco paquetes. Recógelos de la cinta y acomódalos en la zona de despacho para completar el turno.
